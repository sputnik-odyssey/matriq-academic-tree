# MatriQ Academic Tree

探索量子物理研究者之间的科研与职业关联。网站提供中英文姓名、机构和论文搜索，人物名录、机构筛选、一至三度图谱展开、最短关系路径、SVG 导出和来源记录查看。

## GitHub Pages 发布

这是无需安装依赖的静态网站。发布文件都在仓库根目录。

在仓库 **Settings → Pages** 中选择 **Deploy from a branch**，分支选 **main**，目录选 **/ (root)** 并保存。GitHub Pages 发布完成后，可将生成的网站链接分享给任何人。

本地预览可运行 `python3 -m http.server 8765 --bind 127.0.0.1`，然后打开 `http://127.0.0.1:8765/`。

## 公开数据范围

`data.json` 保留人物姓名、专业教育与机构信息、个人学术主页和公开身份链接、论文记录，以及关系字段和原始行号。公开版本不包含联系状态、招聘评估、跟进进展、内部备注或原始工作簿。

人物身份未能充分确认时分别保留档案；只在关系字段出现的对象使用虚线边框。连线表示源表记录的关联，不自动等同于博士或博后指导关系，不表示学术辈分或时间方向。机构名称保留源表写法，别名可能分别统计。数据尚未经过逐条外部核实。

## 贡献与更正

欢迎提交 Issue 或 Pull Request 改正人物姓名、机构、学位或关系。请提供可公开访问的机构主页、学位论文或论文等证据，并尽量注明现有档案编号和来源行号。请勿提交私人联系方式、招聘或联系记录，以及未经证实的个人评价。

页面入口为 `index.html`，交互代码为 `app.js`，样式为 `style.css`。修改数据后请确保节点编号唯一、关系端点存在，并保留来源证据。
