# MatriQ Academic Tree

探索量子物理研究者之间的科研与职业关联。网站提供中英文姓名、机构和论文搜索，人物名录、机构筛选、一至三度图谱展开、最短关系路径、SVG 导出和来源记录查看。

在线访问：[MatriQ Academic Tree](https://sputnik-odyssey.github.io/matriq-academic-tree/)

## GitHub Pages 发布

这是无需安装依赖的静态网站。发布文件都在仓库根目录。

在仓库 **Settings → Pages** 中选择 **Deploy from a branch**，分支选 **main**，目录选 **/ (root)** 并保存。GitHub Pages 发布完成后，可将生成的网站链接分享给任何人。

本地预览可运行 `python3 -m http.server 8765 --bind 127.0.0.1`，然后打开 `http://127.0.0.1:8765/`。

## 公开数据范围

`data.json.gz` 是 gzip 压缩的 JSON 数据，保留人物姓名、专业教育与机构信息、个人学术主页和公开身份链接、论文记录，以及关系字段和原始行号。网站会在浏览器中解压数据；需使用支持 `DecompressionStream` 的现代浏览器。若服务器已自动解压，网站可直接读取返回的 JSON。公开版本不包含联系状态、招聘评估、跟进进展、内部备注或原始工作簿。

人物身份未能充分确认时分别保留档案；只在关系字段出现的对象使用虚线边框。连线表示源表记录的关联，不自动等同于博士或博后指导关系，不表示学术辈分或时间方向。机构名称保留源表写法，别名可能分别统计。数据尚未经过逐条外部核实。

## 贡献与更正

欢迎提交 Issue 或 Pull Request 改正人物姓名、机构、学位或关系。请提供可公开访问的机构主页、学位论文或论文等证据，并尽量注明现有档案编号和来源行号。请勿提交私人联系方式、招聘或联系记录，以及未经证实的个人评价。

页面入口为 `index.html`，交互代码为 `app.js`，样式为 `style.css`。修改数据后请确保节点编号唯一、关系端点存在，并保留来源证据。

## 指导关系和框色

网站使用 MatriQ Atom Lab 的冷蓝灰配色、深蓝画布和 Times New Roman 衬线字体。

框色相对当前选中人物计算：黑框是当前人物，红框是已确认指导链上的上游导师，橙框是下游受指导者，灰框是普通关联或待确认关系。切换中心人物后重新计算。PhD 使用蓝色实线，Postdoc 使用金色虚线；已确认的箭头均为导师 → 受指导者。指导环或方向冲突不会任意着色。

公开指导证据维护在 `mentorships.json`，仅覆盖有明确来源的原有边。需同时填写准确的边编号、导师与受指导者节点编号、阶段、公开来源 URL 和核验日期。不能仅凭 Research Line / Industry Line、PhD 学历或布局位置自动推定指导关系。共同指导关系可能只展示原表已有的一位导师。

`mentorship.mjs` 负责验证证据记录和计算相对角色；`graph-render.mjs` 生成带语义边框、阶段标签和箭头的 SVG。
